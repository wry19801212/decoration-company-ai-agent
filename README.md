# 装修公司智能体交付包

这套文件用于搭建装修公司的 AI 运营智能体系统，覆盖账号搭建、内容运营、拍摄策划、种草文案、活动策划、广告投放、直播运营和年框标书。

## 你会得到什么

- `index.html`：可直接打开使用的装修公司 AI 运营工作台。
- `docs/01-智能体架构.md`：智能体岗位分工、协作流程、输入输出。
- `docs/02-年框服务方案.md`：可对外提案的年度服务框架。
- `docs/03-运营SOP.md`：月度、周度、日常执行流程。
- `docs/04-提示词模板库.md`：给 AI 使用的标准提示词。
- `docs/05-资料收集表.md`：搭建知识库前需要收集的公司资料。
- `docs/06-交付清单与报价.md`：服务清单、交付频次和报价结构。
- `docs/07-落地执行总表.md`：30 天启动计划、团队分工、会议节奏和数据表字段。
- `docs/08-客户使用说明.md`：如何让客户在线使用、打包使用或由你代客户使用。
- `docs/09-部署上线指南.md`：如何部署成客户可访问的在线网页。

## 使用方式

1. 打开 `index.html`。
2. 填写公司基础资料。
3. 选择需要生成的模块。
4. 复制生成的提示词到你正在使用的 AI 工具中。
5. 把产出的内容沉淀到对应的 SOP 和模板中。

## 推荐落地顺序

第一阶段：资料收集、账号搭建、内容选题、拍摄脚本。

第二阶段：种草笔记、私域跟进、活动策划、直播运营。

第三阶段：广告投放、数据复盘、竞品分析、年框标书。

## 适用场景

- 装修公司内部营销部使用。
- 给装修公司做年度代运营服务。
- 作为年框服务投标或提案材料基础。
- 培训设计师、主播、短视频团队统一话术。

## 让客户使用

当前本地预览地址只在这台电脑可用。客户使用建议三种方式：

- 部署成在线网页，客户通过链接打开。
- 打包 `index.html`、`style.css`、`script.js`、`docs` 文件夹给客户本地打开。
- 你代客户填写资料，生成内容后整理成交付方案。

详细流程见 `docs/08-客户使用说明.md`。
