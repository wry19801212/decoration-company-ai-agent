# 装修公司智能体架构

## 总体定位

装修公司智能体不是单个聊天工具，而是一组围绕“获客、信任、转化、复盘”运转的 AI 岗位。它的核心价值是把老板、运营、设计师、摄影、投手、主播的经验沉淀成稳定流程。

## 智能体岗位

| 智能体 | 主要职责 | 输入 | 输出 |
| --- | --- | --- | --- |
| 品牌策略智能体 | 公司定位、客户画像、差异化卖点 | 公司资料、案例、竞品 | 品牌定位、账号主线、年度策略 |
| 账号搭建智能体 | 平台定位、主页包装、账号矩阵 | 城市、业务、目标客户 | 账号名、简介、主页规划、置顶内容 |
| 内容运营智能体 | 选题、标题、内容排期 | 业务目标、活动节点 | 月度选题表、周度发布表 |
| 拍摄策划智能体 | 分镜、口播、场景、素材清单 | 选题、案例、工地信息 | 拍摄脚本、镜头清单、出镜安排 |
| 种草转化智能体 | 小红书、案例包装、私信引导 | 案例、预算、客户痛点 | 种草笔记、封面标题、私信话术 |
| 活动策划智能体 | 获客活动、节点营销、老带新 | 楼盘、节日、优惠政策 | 活动方案、传播排期、成交机制 |
| 广告投放智能体 | 素材方向、预算、测试、复盘 | 投放目标、预算、线索数据 | 投放计划、素材测试、复盘建议 |
| 直播运营智能体 | 直播主题、流程、话术、追单 | 活动、主播、案例、福利 | 直播脚本、场控表、跟进SOP |
| 年框标书智能体 | 年度服务包装、报价、标书 | 服务范围、客户需求、资源 | 年框方案、报价表、投标文件 |

## 协作流程

1. 品牌策略智能体先确定“这个公司凭什么被本地业主选择”。
2. 账号搭建智能体把定位翻译成平台主页和账号矩阵。
3. 内容运营智能体把目标拆成月度选题和发布节奏。
4. 拍摄策划智能体把选题变成可执行拍摄脚本。
5. 种草转化智能体把案例、预算、避坑内容改写成小红书笔记。
6. 活动策划智能体把节点、楼盘、优惠变成获客活动。
7. 广告投放智能体挑选最适合投放的素材和落地页结构。
8. 直播运营智能体承接活动流量，完成预约和到店转化。
9. 年框标书智能体把上述能力包装成年度服务方案。

## 数据闭环

每周记录：

- 发布内容数量
- 爆款内容主题
- 私信数量
- 表单线索
- 预约量房
- 到店咨询
- 成交辅助
- 广告消耗
- 单线索成本
- 直播预约数

每月复盘：

- 哪类内容带来线索
- 哪类案例最容易被收藏
- 哪类活动最容易到店
- 哪类广告素材成本最低
- 哪些话术带来高质量客户

## 最小可行版本

第一版只需要跑通 3 个智能体：

1. 账号内容智能体：账号搭建、选题、标题、脚本。
2. 活动直播智能体：活动方案、直播流程、转化话术。
3. 年框方案智能体：服务清单、报价、标书结构。

跑通之后再扩展投放、数据分析和私域跟进。
