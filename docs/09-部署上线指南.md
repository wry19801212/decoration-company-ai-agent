# 装修公司智能体部署上线指南

## 先判断

这套工作台是纯静态网页，核心文件只有：

- `index.html`
- `style.css`
- `script.js`
- `docs` 文件夹

不需要服务器程序，不需要数据库，也不需要安装依赖。

## 方式一：Netlify 拖拽部署

适合：最快给客户一个在线链接。

### 操作步骤

1. 打开 Netlify。
2. 注册或登录账号。
3. 进入项目页面，找到拖拽部署区域。
4. 把整个 `装修公司智能体` 文件夹拖进去。
5. 等待上传完成。
6. Netlify 会生成一个网址，格式类似：

```text
https://xxxxxx.netlify.app
```

7. 把这个网址发给客户。

### 优点

- 最快。
- 不需要写代码。
- 适合先给客户试用。

### 缺点

- 后续每次更新，都要重新上传一次文件夹。
- 如果要绑定自己的域名，需要再做域名设置。

## 方式二：GitHub Pages

适合：长期维护，版本稳定。

### 操作步骤

1. 注册或登录 GitHub。
2. 创建一个新仓库。
3. 上传以下文件：
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
   - `docs` 文件夹
4. 进入仓库设置。
5. 找到 Pages。
6. 选择从主分支部署。
7. 保存后等待几分钟。
8. GitHub 会生成一个网址，格式类似：

```text
https://你的用户名.github.io/仓库名/
```

### 优点

- 稳定。
- 适合长期更新。
- 每次改文件后，网站可以自动更新。

### 缺点

- 初次设置比拖拽部署稍微复杂。
- 客户如果完全不懂电脑，建议由你来操作。

## 方式三：Vercel 部署

适合：已经习惯使用 GitHub，想要更标准的网站发布流程。

### 操作步骤

1. 注册或登录 Vercel。
2. 连接 GitHub 仓库。
3. 导入这个项目。
4. 框架选择 Other 或静态项目。
5. 不需要填写构建命令。
6. 发布目录保持根目录。
7. 点击 Deploy。
8. 获得一个网址，格式类似：

```text
https://xxxxxx.vercel.app
```

## 方式四：自有服务器或宝塔面板

适合：你已经有公司官网或服务器。

### 操作步骤

1. 在服务器上创建一个站点。
2. 把项目文件上传到站点根目录。
3. 确保 `index.html` 在根目录。
4. 绑定域名。
5. 开启 HTTPS。

### 适合域名

```text
https://ai.你的域名.com
https://agent.你的域名.com
https://你的域名.com/agent
```

## 推荐给客户的交付方式

如果是试用客户：

```text
Netlify 拖拽部署 -> 发临时链接 -> 客户试用
```

如果是年框客户：

```text
GitHub Pages 或 Vercel -> 绑定正式域名 -> 纳入年度服务
```

如果是装修公司内部使用：

```text
部署到公司官网子域名 -> 只发给内部团队
```

## 上线前检查

上线前打开网页，确认：

- 公司资料可以填写。
- 模块可以切换。
- AI提示词和执行框架可以切换。
- 复制结果可用。
- 导出 Markdown 可用。
- 手机端能正常浏览。

## 给客户的网址话术

```text
这是给您搭建的装修公司 AI 运营工作台：

【放上线网址】

您打开后先填写公司资料，再选择账号搭建、内容选题、拍摄脚本、活动策划、直播运营或年框标书等模块。

如果选择“AI提示词”，可以复制到常用 AI 工具里继续生成完整内容。
如果选择“执行框架”，可以直接给运营、设计师、主播或客服照着执行。
```

## 重要提醒

- 不要把本机地址 `127.0.0.1` 发给客户，这个地址只有你自己的电脑能打开。
- 如果客户需要保存多人数据、登录账号、权限管理，就需要升级成带后端的系统。
- 当前版本适合做“轻量工作台”和“年框服务交付工具”。
