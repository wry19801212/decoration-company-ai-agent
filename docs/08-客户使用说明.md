# 客户使用说明

## 先说明

当前工作台地址 `http://127.0.0.1:4173/index.html` 只在本机可用。客户如果不在这台电脑上，不能直接打开这个地址。

要让客户使用，有三种方式：

1. 部署成网页，客户通过链接打开。
2. 打包成文件，客户在自己电脑上打开。
3. 你帮客户代填资料，生成结果后交付给客户。

## 推荐方式一：部署成网页

适合长期服务客户和年框客户。

### 客户使用流程

1. 客户打开你提供的网址。
2. 填写公司资料：公司名称、城市、业务、客户、客单价、优势、目标。
3. 选择需要的模块：
   - 账号搭建
   - 内容选题
   - 拍摄脚本
   - 种草笔记
   - 活动策划
   - 广告投放
   - 直播运营
   - 年框标书
   - 私域跟进
   - 数据复盘
   - 竞品分析
   - 标书目录
4. 选择生成模式：
   - AI提示词：复制到 AI 工具里，让 AI 继续生成完整内容。
   - 执行框架：直接作为内部执行方案使用。
5. 点击复制或导出 Markdown。

### 适合给客户的话术

```text
我们给您搭建了一个装修公司 AI 运营工作台。

您只需要填写公司基础资料，就可以生成账号搭建、内容选题、拍摄脚本、小红书种草、活动策划、广告投放、直播运营、私域跟进和年框方案等内容。

这个工具主要用于统一运营思路、提高内容生产效率，也方便我们后续按月做复盘和优化。
```

## 推荐方式二：打包给客户

适合客户暂时不需要在线系统，只想先试用。

### 交付文件

把以下文件一起压缩给客户：

- `index.html`
- `style.css`
- `script.js`
- `README.md`
- `docs` 文件夹

### 客户打开方式

客户解压后，双击 `index.html` 即可打开。

如果客户电脑限制本地脚本，可以让客户使用浏览器打开，或由你帮客户部署成在线链接。

## 推荐方式三：代客户使用

适合前期成交和年框提案。

### 操作流程

1. 先让客户填写 `docs/05-资料收集表.md`。
2. 你把资料填入工作台。
3. 生成账号方案、月度内容、活动方案、直播脚本和年框标书。
4. 整理成 Word、PPT 或月度运营表交付客户。

### 适合场景

- 客户不懂 AI。
- 客户不愿意自己操作。
- 你要体现服务价值，而不是只交一个工具。
- 你要把它包装成年框服务的一部分。

## 给客户的第一天使用任务

第一天不要让客户一次性用完所有模块。建议只让客户做 3 件事：

1. 填写公司资料。
2. 生成账号搭建方案。
3. 生成 30 天内容选题。

完成后，你再帮客户筛选：

- 哪些内容适合马上拍。
- 哪些内容适合投放。
- 哪些内容适合做小红书。
- 哪些内容适合放进年框方案。

## 客户培训话术

```text
这个工作台不是让 AI 替代运营团队，而是把运营团队的工作标准化。

以前做账号、拍摄、活动、直播，很多内容靠经验和临时沟通。现在我们把这些流程拆成固定模块，客户资料一填，就能生成标准化的执行方向。

后续我们每个月会根据真实数据调整选题、活动、投放和直播，这样账号不是靠感觉做，而是按数据持续优化。
```

## 年框客户使用方式

对年框客户，建议你不要只交工具，而是这样包装：

### 第 1 周

- 完成资料收集。
- 搭建账号定位。
- 输出首月内容计划。

### 第 2 周

- 完成第一批拍摄脚本。
- 做一次集中拍摄。
- 开始发布和记录数据。

### 第 3 周

- 做小红书种草和私域跟进。
- 策划一个小活动或直播。

### 第 4 周

- 汇总数据。
- 做月度复盘。
- 优化下月内容和活动。

## 注意事项

- 客户填写的信息越具体，生成结果越好。
- 不要让客户直接用空资料生成方案。
- 所有活动、报价、优惠、施工承诺必须真实。
- 广告投放建议需要结合真实预算和账户数据复盘。
- 年框标书可以用 AI 起草，但最终报价和服务边界要人工确认。
