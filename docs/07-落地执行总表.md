# 装修公司智能体落地执行总表

## 30 天启动计划

| 天数 | 目标 | 关键动作 | 交付物 |
| --- | --- | --- | --- |
| 第1-2天 | 收集资料 | 填写资料收集表，整理案例、团队、服务、报价 | 公司知识库初稿 |
| 第3-4天 | 确定定位 | 梳理目标客户、业务重点、差异化优势 | 品牌定位和账号主线 |
| 第5-6天 | 搭建账号 | 完成账号名、头像、简介、置顶内容规划 | 账号搭建方案 |
| 第7天 | 建立模板 | 固定选题、脚本、笔记、复盘模板 | 模板库 |
| 第8-10天 | 生成内容 | 产出30天选题和首批脚本 | 月度内容表 |
| 第11-13天 | 集中拍摄 | 拍设计师、工地、材料、案例、活动口播 | 原始素材包 |
| 第14-17天 | 发布测试 | 发布第一批内容，测试标题和封面 | 数据记录表 |
| 第18-20天 | 做种草 | 改写案例笔记、预算笔记、避坑笔记 | 小红书内容包 |
| 第21-23天 | 做活动 | 设计样板间征集或交房季活动 | 活动方案 |
| 第24-26天 | 做直播 | 设计直播主题、话术、福利、追单流程 | 直播脚本 |
| 第27-28天 | 做投放 | 筛选高转化素材，制定预算和测试计划 | 投放计划 |
| 第29-30天 | 做复盘 | 汇总数据，确定下月重点 | 月度复盘报告 |

## 团队分工

| 角色 | 负责事项 | AI 辅助内容 |
| --- | --- | --- |
| 老板/负责人 | 定战略、定政策、拍信任内容 | 品牌定位、老板口播、年框方案 |
| 运营 | 选题、发布、评论、私信 | 选题表、标题、评论回复、复盘 |
| 设计师 | 出镜、讲方案、跟进客户 | 口播稿、客户异议、方案讲解 |
| 摄影剪辑 | 拍摄、剪辑、封面 | 分镜脚本、镜头清单、封面文字 |
| 客服 | 私信、邀约、回访 | 私域话术、7天跟进SOP |
| 投手 | 广告计划和数据复盘 | 素材方向、落地页、A/B测试 |
| 主播 | 直播讲解和互动 | 直播流程、福利话术、逼单话术 |

## 每周固定会议

### 周一内容会

- 确认本周主推业务。
- 确认拍摄选题和出镜人。
- 确认活动和直播节点。

### 周三数据会

- 看前半周内容表现。
- 调整标题、封面、发布时间。
- 标记值得投放的素材。

### 周五转化会

- 看线索质量。
- 看量房和到店情况。
- 安排周末直播、活动和追单。

## 成功标准

30 天内不是追求立刻做成大号，而是完成四件事：

1. 账号定位清晰。
2. 内容能稳定生产。
3. 私信和线索有人跟。
4. 每月能复盘并优化。

只要这四件事跑通，后续就可以持续叠加活动、投放、直播和年框服务。
